---

## ⚙️ Configuration

Edit file config:

```js
module.exports = {
  tokens: "YOUR_TELEGRAM_BOT_TOKEN",
  officialToken: "YOUR_TELEGRAM_BOT_TOKEN",
  owner: "YOUR_TELEGRAM_ID",
  ipvps: "https://yourvpsdomain.com",
  port: "3000"
};
```

---

## 📦 Installation

### 🔹 Install Dependencies
```bash
npm install
```

### 🔹 Run Bot
```bash
node index.js
```

Jika berhasil, bot akan aktif dan siap digunakan ✅

---

## 🛠 Config Explanation

| Field | Description |
|-------|------------|
| 🔑 tokens | Token utama bot Telegram |
| 🛡 officialToken | Token official (biasanya sama dengan tokens) |
| 👑 owner | ID Telegram Owner |
| 🌐 ipvps | Domain VPS |
| 🚪 port | Port server (default: 3000) |
